# Concept plates

Supplied by the owner on 17 November 2026 as `saelion_concepts_5k_bundle.zip` (five PNGs at 5120 × 2880, 86 MB). These are 1600 px JPEG copies for reference; the originals are not in the repo. The bundle's own note says the 5K files are upscales of 1672 × 941 and 1536 × 864 images. No licence or generator is recorded.

| File | What it shows | What the game takes from it |
|---|---|---|
| `01_gen3_storeybrook.jpg` | Gen 3, the Storeybrook plate | Not yet studied closely |
| `02_gen4_fifteen_modes.jpg` | Gen 4 in-game frame; "The 15 Aesthetic Modes, Playable Reality Views"; the toolkit strip; Gen 5 mood library | Views are **playable**, each with a purpose. See the mode table in `docs/PLAN.md` |
| `03_gen5_afterimage.jpg` | Gen 4 shipping look; Gen 5 Afterimage; the fifteen modes again with different names; the radial mode toggle; the Fifteenth Mode, Ætherweave | The radial toggle and the fifteenth mode are targets, not built |
| `04_gen15_skeptic_noir.jpg` | Gen XV Skeptic Noir in play: "Recover the light", a hush running with a lantern's light, the inkblot stag, Myra and the Skein Doll on the steps | The Inkblot Noir view and the thief-with-a-light rule. The HUD line "Recover the light" is a good objective name |
| `05_original_four_looks_reference.jpg` | The four looks from Livloch 0.3 | Reference only |

The first plate in the project, `art/title.jpg`, is the game's title screen.
